# 听说法（Audio-Lingual Method）方法论速查

用于约束逐字稿与 PPT 的生成取向。生成任何内容前先对齐这些原则。

## 核心原则

1. **听说领先，读写跟上**：口语习惯先于文字符号建立。
2. **句型操练为核心**：语言是习惯（habit formation），靠反复操练而非规则理解。
3. **示范 > 解释（多练少讲）**：情境 + 母语者示范呈现语言点；语法讲解都在语法单上，课堂不讲解规则、只操练。
4. **教师主导、即时纠错**：错误当场温和纠正，防固化；正面强化建信心。
5. **对比分析预判偏误**：依学生母语—汉语对比，预先设计易错点操练。
6. **指令分层**：课堂用语（媒介语）与教学内容（目标语）分开。

## 典型课堂环节（逐字稿须覆盖）

| 环节 | 目的 | 常用操练 |
|------|------|----------|
| 热身 Warm-up | 复习、激活话题 | 快速问答、齐诵旧句 |
| 呈现 Presentation | 情境引出新点 | 实物/图片示范、情境对话 |
| 机械操练 Drill | 形成习惯 | 重复、替换、转换、链式、提示—应答、齐读 |
| 意义操练 Meaningful | 控制下运用 | 上下文替换、看图造句 |
| 交际活动 Communicative | 自由运用 | 信息差、角色扮演、调查采访 |
| 作业 Homework | 巩固 | 口头录音、结对练习 |

## 操练类型速记

- **Repetition（重复）**：师说→生跟。
- **Substitution（替换）**：给定框架，替换主语/宾语/时间等。
- **Transformation（转换）**：陈述→疑问、肯定→否定、换时态。
- **Chain（链式）**：S1 问 S2，S2 答并问 S3，循环。
- **Cue-Response（提示—应答）**：师给提示词，生用目标句应答。

## 纠错基调

- 不当众否定人格，只纠正形式。
- 先让全班/同桌重复正确形式，再让该生重试。
- 系统性偏误回到机械操练补练。
