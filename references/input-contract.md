# 输入契约（详细说明）

生成前必须确认以下字段齐全。缺失则补全或显式询问用户。

## 课文

| 字段 | 必填 | 说明 | 示例 |
|------|------|------|------|
| 标题 | 是 | 单元/课文名 | 《在餐厅点餐》 |
| 文本 | 是 | 原文，对话体或短文 | A：你要点什么？B：我要一碗牛肉面…… |
| 水平 | 是 | HSK 或 CEFR | HSK3 / B1 |
| 话题 | 是 | 主题分类 | 餐饮、出行、社交 |
| 字数 | 否 | 控时用 | 约 120 字 |

## 语法单

| 字段 | 必填 | 说明 | 示例 |
|------|------|------|------|
| 语法点 | 是 | 目标结构名 | "把"字句 |
| 目标句型 | 是 | 要掌握的句式模板 | S + 把 + O + V + 其他 |
| 例句（正） | 是 | 正确示范 | 我把书放在桌上了。 |
| 例句（误） | 否 | 典型误例，用于纠错演示 | 我放书在桌上。（×） |
| 操练目标 | 是 | 学完能做到什么 | 能用"把"字句描述物品位置移动 |
| 常见偏误 | 否 | 对比分析预测 | 遗漏"了"、宾语非定指 |

## 最小可用输入

若用户只给课文，可推断 1–2 个核心语法点生成初稿，并在交付时提示："建议补充语法单（语法点/目标句型/操练目标）以精修操练环节。"
