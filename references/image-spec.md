# 讲练例句图片规范（Image Spec）

## 一、图片的本质

在听说法课堂里，图片**不是装饰，而是操练的视觉触发物**：学生看着图，回答教师的替换问答、产出目标句。找图 / 配图是备课里繁琐的一环，本 Skill 用**《图片需求清单》**替教师解决"不知道每句要配什么图"的前半段：

- **本 Skill 只产出清单**：在逐字稿里用 `【配图：…】` 标注图片触发点，并在文末汇总《图片需求清单》，告诉教师「每个操练例句该配一张什么样的图」。
- **本 Skill 不生成图片**：图片由教师自行找图，或用任意文生图工具按清单生成；清单里的"图片内容"即文生图 prompt 要点。

> 设计意图：把「想清楚要配哪些图」这件费脑的事交给 Skill，把「真的去找图/生成图」这件纯执行的事留给教师或通用工具——聚焦逐字稿这个核心。

## 二、图片识别规则（关键，此前有误，已纠正）

**图片的计量单位不是"关键词"，而是"操练例句"。**

- 每个语法点按**四梯度句型**设计 4 组递进例句（课文范句 → 课内拓展句 → 课外实景句 → 对比辨析句）；其中**课外实景句**（三贴近）最需要配图。
- **每一个例句，除了它复用的"课文既有生词"以外，句子引入的新情境/新内容，都需要一张图片来提示（看图问答）**。
- 也就是说：**图片数量 ≈ 各语法点课外实景句数量之和**（约 2–4 张/语法点）。以 L24 为例，14 个语法点 ≈ **40–56 张**量级——这是真实备课的找图规模，不是装饰性几张。
- 例外（不单独配图）：① 直接复用课文原句、无新情境的例句；② 纯抽象/可文字或图示表达的例句（如"他降低了成本和质量"，可用简图或文字）。判断标准：**学生一眼看懂情境即可作答 → 配图；否则文字/图示即可**。

## 三、标注约定

- 逐字稿环节内标注（贴在对应例句后）：`【配图：一句话描述图面内容 / 给图片模型的 prompt 要点】`
- 文末汇总《图片需求清单》（下表格式），供教师自行找图或喂给文生图工具。

## 四、《图片需求清单》格式

| 序号 | 所属语法点 / 例句 | 图片内容描述（prompt 要点） | 触发问答 / 用途 | 风格要求 |
|---|---|---|---|---|
| 1 | 来表目的·例2 | 城市工地修地铁建高楼 | 大同政府做了什么来发展旅游业？ | 真实场景照 |

## 五、风格约定（默认）

- **真实照片质感优先**（贴近"看实物 / 看场景"触发），除非教师指定插画风。
- 图中**不要预先印好目标句文字**（句子由师生口头产出）；可含实物本身的标签（如衣服"Made in China"、商品价格牌）。
- 每图聚焦**单一可指场景**，学生一眼看懂即可作答。
- **配图要能被识别为目标内容**：图面必须含能一眼识别出操练目标的元素（如操练"英语"就配英文书/英文招牌，而不是"教室里的一班学生"这类泛化图），让学生看图即能产出目标句。
- 文化准确性：中国场景用真实中国元素（火锅店、地铁、阳台晾衣、古董市场…），避免西方刻板符号。

## 六、从 L24 样课校准的图片需求（节选，完整清单见生成的逐字稿）

> 此前误把"关键词"当计量单位（礼物/把…送给…各一张）。按新规则，应为**每个操练例句（主要是课外实景句）的新情境一张图**。下面按语法点列出，每点约 3–4 张，量级 40–56：

| 语法点 | 操练例句（新情境 → 图片） |
|---|---|
| 来表目的 | ①海关手持《花花公子》→ ②政府修地铁建高楼发展旅游 → ③中国人说"到时候再说"拒绝 |
| 送/把…送给 | ①拎礼物袋敲朋友门 → ②山水画礼盒 → ③过生日送蛋糕 |
| 人们常说 | ①坐/蹲厕对比 → ②阳台晾衣 → ③早睡早起俗语 |
| 最…的 | ①珠峰 → ②秦始皇/兵马俑 → ③labubu 热门商品 |
| 造成 | ①高架堵车 → ②方言沟通困难 → ③繁体字辨识影响 |
| 失业/就业 | ①招聘栏求职 → ②失业者在家 → ③就业环境差后果 |
| 成本/价钱 | ①老板对账本皱眉(成本50卖30) → ②纽约高价街景 → ③北京/家乡生活成本 |
| 使/让 | ①火锅店聚餐 → ②私家车堵车 → ③妈妈说"让"交男友 |
| 享受 | ①惬意北京生活 → ②火锅店周到服务 → ③火车看风景 |
| 对…做出贡献 | ①科技专家 → ②政府修地铁建高楼 → ③特朗普经济 |

> 完整《图片需求清单》随逐字稿一并生成，按「所属语法点/例句 + 图片内容 + 触发问答 + 风格」四列列出，供教师自行找图或喂给文生图工具。
