## 设计初衷

普林斯顿北京班（Princeton in Beijing）有一套成熟的「明德模式」教学法，对教师的备课、逐字稿设计提出了很高要求。这个标准化的 Skill 文档，帮助教师对齐明德模式下严格的教学法需求，以更高的效率完成备课。

---

## 一句话

让 AI 按普北班（Princeton in Beijing）的备课准则来备课：句本位教学、例句三贴近（贴近学生生活、贴近美国文化、贴近中文学习日常）、精讲多练、梯度提问、对课本内容的「跳进跳出」。

---

## 它能帮你做什么

1. **省下逐字稿打磨的时间**：给一篇课文 + 语法单，几分钟出稿，你只需微调。
2. **新手也能备出普北班水准的课**：内置一套自上而下四层的备课准则，当「带教」用。
3. **顺手告诉你该配哪些图**：逐字稿里标好每个例句的配图点，文末汇总《图片需求清单》，找图不再靠临时想。

## 内置的备课准则（自上而下四层）

| 层级 | 要点 |
|---|---|
| **三大核心原则**（总纲） | ① 严格纠音（准确优先）　② 锚定课文（从课文来、回课文去）　③ 多练少讲（语法在语法单上） |
| **句本位备课意识**（怎么备） | 整句输入、整句输出 · 四梯度句型（课文范句→课内拓展→课外实景→对比辨析）· 三贴近 · 范句自然 · 梯度提问 |
| **课堂流程**（怎么上） | 热身小考 → 课堂导入（杜绝闲聊）→ 跳进跳出精讲 → 分层操练成段表达 |
| **贯穿纪律**（全程守住） | 不低龄化 · 不说「对不起」 · PPT 不放例句 |

> 「跳进跳出」= 每个语法点从课文范句进入（跳进）→ 用课外实景句操练（跳出）→ 升维回到课文收束（跳回），全程锚定课文，不脱离文本发散。

## 工作流

```
课文 + 语法单  →  逐字稿（含《图片需求清单》）  →  教师微调  →  上课
```

**范围**：本 Skill 只做逐字稿（纯文本），不生成图片、不生成 PPT。
